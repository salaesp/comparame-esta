# Comparame esta

Sacale fotos a tus tickets y mirá dónde está más barato cada producto, con los precios de tus
amigos. La IA de Anthropic (Claude) lee los productos de las fotos, aunque un ticket largo vaya en
varias fotos que se pisan.

- Diseño y decisiones: [`docs/diseno.md`](docs/diseno.md)
- Cómo ponerla en marcha: [`docs/setup.md`](docs/setup.md)
- Sistema de diseño: `/design-system` (el "Suave" de Gastienzos)

`npm install`, `npm test`, `npm run preview`.
